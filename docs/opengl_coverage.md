# NXGL OpenGL 1.1-1.3 Coverage Plan

This is the working compatibility map for NXGL. A feature only moves to verified
after it has a focused ROM-level probe and builds into a release ISO.

Status values:

* `missing` - no public API yet.
* `stub` - API exists but does not implement useful behavior.
* `partial` - useful subset exists, with known gaps.
* `hardware` - maps directly to NV2A/native renderer behavior.
* `fallback` - implemented in software or CPU-side translation.
* `verified` - covered by an nxdk test app.

## Near-Term Milestones

1. Fill out OpenGL 1.1 headers and no-op/error-correct entry points.
2. Add mipmap image levels/completeness rules and `glTexParameter` LOD fields.
3. Add depth/stencil readback or document it as intentionally unsupported.
4. Add depth/stencil pixel transfer or document it as intentionally unsupported.
5. Promote `glGetString(GL_VERSION)` to `1.1` only after the 1.1 table has no `missing` required rows.
